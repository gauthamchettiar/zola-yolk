{# wide shortcode — lets content break out of the normal reading column. Usage: {% wide() %} ![a wide screenshot](/images/wide.png) {% end %} {% wide(size="xl") %} Spans the whole screen. {% end %} Parameters: size — sm | md | lg | xl (default: "md") Widths live in CSS (.wide in sass/_components.scss), so adding a size is a one-line change there. Every size is capped at the viewport minus the page gutter, so on narrow screens they all fall back to the normal column width. #}
